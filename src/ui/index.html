How to use

  1. Settings: fill the sheet web app URL and token, the admin account and a limited member account. Save.
  2. Sheet > Sync tests to the sheet once, so every test has a row.
  3. Run tests: pick modules / kinds, keep "Write results to the sheet" on, click Run.
  4. In the spreadsheet: Dashboard for totals, QA Dashboard for what to test next, Dev Dashboard for failed tickets; Test Cases has the Result and Notes per case.
  5. Dev tickets: type the ticket number(s) in a case's Dev Ticket column on Test Cases. When a ticket is Ready for QA, put its number in "Only tests for dev ticket(s)" and Run.
  6. Data tests need the value from the original site in Reference (original). Until then they are Blocked and their notes show the Vercel value.
  7. To stop testing a case, set its Case Status to Closed (page discontinued) or Reworked (put the reworking ticket in Reworked By). Set it back to Active to resume.
  8. Results: Pass, Fail, Blocked (could not run), Not Implemented (on the original, not on Vercel yet).

Adding a test: see docs/ADDING-A-TEST.md in this folder.
